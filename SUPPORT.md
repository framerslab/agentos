# Support

- **Questions and discussion:** [Discord](https://wilds.ai/discord). GitHub issues are for bugs and feature requests.
- **Documentation:** [docs.agentos.sh](https://docs.agentos.sh)
- **Bugs and feature requests:** the [issue forms](https://github.com/framerslab/agentos/issues/new/choose). Search the existing issues first.
- **Security issues:** report privately as the [security policy](https://github.com/framerslab/agentos/blob/master/.github/SECURITY.md) describes, never in a public issue.
- **Commercial, partnership or sponsorship inquiries:** team@frame.dev (see [SPONSORS.md](https://github.com/framerslab/agentos/blob/master/SPONSORS.md))

To contribute, see [CONTRIBUTING.md](https://github.com/framerslab/agentos/blob/master/CONTRIBUTING.md).
