# GMI versus agent(): the research paper

This directory holds the method draft of a paper on the GMI versus agent() study: [paper.md](paper.md), its numbered [references](references.md), and a [figures](figures/README.md) directory.

The study's published report sets are under `reports/`, one directory per set, each with a README that lists its files; the study page lists every set.

Status: Method draft. Results pending the confirmatory analysis.

The study's page on the docs site: [GMI versus agent() Study](https://docs.agentos.sh/benchmarks/gmi-vs-agent).

Each file is plain markdown that GitHub renders; a LaTeX build adds `references.bib` when the results are written.
