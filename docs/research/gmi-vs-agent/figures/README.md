# Figures

This directory holds the paper's figures as SVG files that the study's report generator draws from a report's own inputs, each with a caption that names the analysis run that made it. It holds no figure before the confirmatory analysis has run. The planned figures are each arm's score with its interval per task family, the cost per turn per arm, and the first-token and last-token latency per arm at the median and the 95th percentile, with Z drawn as a reference line in every figure and never as a contestant.
