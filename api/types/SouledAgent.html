Return type of souledAgent: an Agent with its backing Memory store exposed as memory, so callers can fold conversation into the wiki mid-session via await agent.memory.compileWiki(). memory and the members below are present whenever the soul resolves to a workspace directory; they are absent for inline souls that fall back to a plain agent.

  • forgetUser?:function
    • forgetUser(userId, options?): Promise<ForgetMemoryReport>

    • Deletes one person's memory from this agent's store for good and keeps it deleted: it waits for the person's pending writes (up to pendingWritesTimeoutMs), records a tombstone, deletes their traces, document chunks, compiled pages and registry row, writes the vector index again, and empties the sessions this handle holds open for them: on the legacy runtime each session's history is cleared; with runtime: 'gmi' each session's messages go at once and its GMI drops its history, its reasoning trace, its sentiment trend, its working-memory slots and its metaprompts' imprints once no turn of the session runs, which the call waits for up to pendingWritesTimeoutMs. A session still running a turn then leaves the report's sessions part missed, and is emptied when that turn ends. With a learning layer, the layer's own deletion runs first, and agent.learning.forgetUser(userId) runs this same deletion. linkedSessions names the anonymous sessions the host has tied to the person: each is deleted the same way, and its counts add into the report's parts.

      Returns Promise<ForgetMemoryReport>

      One report for the user and the linked sessions, the receipt a host keeps beside its own record of the request: each store with reached and a count or a reason, the pages deleted and those that failed, drained, pendingAtDeadline, complete, completedAt, agentId, libraryVersion, the four parts in order (tombstone, mind, store, sessions) and recipients. It never holds the user's id, a hash of the id or any text. The person's deletion and each linked session's write one memory.forget_incomplete warn line when incomplete, with each part reached or missed.

      Throws

      TypeError when userId, or an entry of linkedSessions, is not a non-empty string, or holds a NUL or a lone surrogate, so no memory key can be built from it; nothing is deleted and no tombstone is written.

  • exportUserMemory?:function
    • exportUserMemory(userId): Promise<UserMemoryExport>

    • One person's memory as JSON: their conversation traces (id, time, speaker, text, tags) and their compiled pages (id, summary, updated, sources, body), read from their own scope alone; what they provided (their own messages); what is held about them (each trace with its entities, filing side, emotional context and strength fields, the memory graph's links between their traces, their pages, and their learned state when the agent runs a learning layer); SouledAgent.recipients; the retention period; whether their messages are scored for sentiment; and each read that failed (unread). Operator pages, other people's memory and a gmi() session's history are not in it; a forgotten person's export holds nothing of them. It reads after the memory writes of the person's turns already sent, so a turn whose send() resolved before the call is in it.

    Deletes or corrects one person's memories. It deletes the named traces for good, deletes each page built from a deleted trace and has the next compile build it again from the traces that are left. With text it files text in their place, as a trace tagged correction; with no text it files nothing. It rejects, and changes nothing, when any id is not one of that person's live traces. When the person's memory already holds text word for word, that trace is the correction: it is tagged correction, kept, and not deleted even when it is one of the named traces. No newer statement replaces an older one by itself: this call is how one does.

    A session turn of the person that was running when the call changed their memory does not file its reply, which can restate what the turn recalled before: the turn's memoryWrite names the reply skipped, corrected. What the person said in that turn is filed.

    Returns

    How many traces and pages it deleted, and recipients, the list SouledAgent.recipients returns: the call sends them nothing, so telling each one is the host's. A correction adds correctionTraceId, the id of the correction's trace, a live trace; a deletion with no text has no such key.

    Throws

    TypeError when userId or the trace ids are missing, or when text is given and is not a non-empty string: a deletion leaves text out.

    Throws

    Error when the correction's trace was deleted before it was marked; the call deletes no named trace. The same call made again files the correction anew when every named trace is still live; otherwise it rejects.
