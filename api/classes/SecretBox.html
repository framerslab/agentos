Class SecretBox

Seals a run's meeting url at rest under the current 32-byte key, with the library's AES-256-GCM sealing (sealSecret, openSecret). Previous keys open older texts. Every seal uses a fresh nonce and the stored form remains v1.box.<base64url(nonce | ciphertext | tag)>. The run's id is bound as context, so moving a text to another row fails.
