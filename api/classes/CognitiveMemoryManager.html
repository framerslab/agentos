forSession

  • forSession(): ICognitiveMemoryManager

  • This manager as one session sees it: the same store, graph and mechanisms, with a working memory of its own. encode, retrieve and assembleForPrompt on the view focus traces in that working memory, and the view's active context lists only the traces the session encoded or recalled. Sessions that call the manager directly share its one working memory, whose slot list (trace ids and activations) is part of every assembled context.

    shutdown() on the view does nothing: whoever owns the manager shuts it down.

    Returns ICognitiveMemoryManager

    A view to hand to one session (one GMI).

observe

  • observe(role, content, mood?, options?): Promise<null | ObservationNote[]>

  • Feed a conversation message to the observation pipeline.

    Pipeline flow:

    1. Observer extracts typed observation notes from buffered messages
    2. Notes are fed to the Reflector for consolidation into long-term traces
    3. Reflected traces are encoded via encode() (typed as semantic/episodic/etc.)
    4. Superseded traces are soft-deleted
    5. Commitment and intention notes are auto-registered with ProspectiveMemoryManager

    Parameters

    • role: "user" | "assistant" | "system" | "tool"

      Message role (user, assistant, system, tool)

    • content: string

      Message text content

    • Optional mood: PADState

      Optional PAD emotional state at observation time

    • Optional options: {
          contentSentiment?: number;
      }
      • Optional contentSentiment?: number

    Returns Promise<null | ObservationNote[]>

flushReflection

  • flushReflection(mood?, scopeOverride?): Promise<FlushReflectionResult>

  • Step-8: Force the reflector to run over pending notes regardless of threshold. Encodes reflection traces, soft-deletes superseded IDs. Safe to call when no reflector or no pending notes exist (returns an empty result). Errors do not propagate — reflection is non-critical.

setHydeRetriever

  • setHydeRetriever(retriever): void

  • Attach a HyDE retriever to enable hypothesis-driven memory recall.

    When set, the retrieve() and assembleForPrompt() methods can accept options.hyde = true to generate a hypothetical memory trace before searching. This improves recall for vague or abstract queries by producing embeddings that are semantically closer to stored traces.

    Parameters

    • retriever: null | HydeRetriever

      A pre-configured HydeRetriever instance, or null to disable HyDE.

    Returns void

    Example

    memoryManager.setHydeRetriever(new HydeRetriever({
      llmCaller: myLlmCaller,
      embeddingManager: myEmbeddingManager,
      config: { enabled: true },
    }));

applyRecallConfig

  • applyRecallConfig(recall): Promise<void>

  • Replaces recall settings on a built manager, field by field over the ones it holds: for a host or a bench that is handed a manager it did not construct. The values are checked as at construction. A rerank builds that provider and starts its load, and the call resolves when the load has settled (loaded or unavailable); until then turns run unreranked, reason loading. This is the only way to change rerank on a built manager: its provider is built once.

    Parameters
