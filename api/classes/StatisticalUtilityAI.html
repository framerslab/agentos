summarize

  • summarize(textToSummarize, options?): Promise<string>

  • The first sentences of the text, joined by spaces.

    How many: 3 unless desiredLength says otherwise. 'short' is 2, 'medium' 30 percent of the sentences and at least 3, 'long' half of them and at least 4. A number of 1 or less is a fraction of the sentences, rounded, so 0 asks for none; a larger number is a count; a number that is not a number (NaN) keeps the default. analyzeSentiment

  • analyzeSentiment(text, options?): Promise<SentimentResult>

  • Scores a text's sentiment with a word lexicon, with no model call.

    The lexicon is the first one natural ships for the language (options.language, else sentimentConfig.defaultLexiconLanguage, else defaultLanguage): AFINN for English, Spanish and Portuguese, pattern for French, German, Italian and Dutch, senticon for Catalan, Basque and Galician. The entries of sentimentConfig.lexiconPath join it in the default lexicon language. options.lexiconNameOrPath picks another of natural's lexicons by name ('afinn', 'afinnFinancialMarketNews', 'pattern', 'senticon'), or a file that is then the lexicon alone. Another language scores 0 unless lexiconPath gives it words.

    The text is read as words (letters, marks and digits, an apostrophe inside a word kept, lower case) in clauses that end at . , ; : ! ? or …. At each word, a phrase the lexicon lists that starts there (can't stand, not good, well-being; the longest when several do) takes its value; else a negation word of the language (in English not, no, never, neither and any word ending in n't) flips the value of the lexicon entries that start among the next three words of its clause; else a word the lexicon lists takes its value. A word scores only in a form the lexicon lists: nothing is stemmed. score is the sum of the values put on AFINN's scale (pattern and senticon values times 5) and mapped into -1 to 1 as VADER maps its compound score: s / sqrt(s * s + 15). polarity is positive from 0.05, negative from -0.05, else neutral; intensity is the score's size; comparative is the sum over the number of words, as natural computes it. positiveTokens and negativeTokens hold each scored word or phrase with its signed value, and neutralTokens the other words.

    Parameters

    • text: string
    • Optional options: SentimentAnalysisOptions

    Returns Promise<SentimentResult>

    Throws

    NOT_SUPPORTED when lexiconNameOrPath names a lexicon natural has no version of in the language, and RESOURCE_NOT_FOUND when it names a file that cannot be read.

detectLanguage

  • detectLanguage(text, options?): Promise<LanguageDetectionResult[]>

  • Detect the language of a text with the package's 21 language profiles.

    The script that holds more than half of the text's letters decides first: Hangul is Korean, Han with kana that make up a tenth of those letters or more is Japanese and with fewer Chinese, and Arabic, Devanagari, Bengali and Cyrillic text is Arabic, Hindi, Bengali, Russian or Ukrainian when its letters show which; that language comes back alone. Latin-script text is ranked against 13 trigram profiles (English, Spanish, French, German, Portuguese, Italian, Dutch, Turkish, Vietnamese, Polish, Swedish, Danish, Norwegian) by Cavnar and Trenkle's out-of-place distance.

    A text shorter than 10 characters after trimming, and one the profiles do not decide, answers [{ language: defaultLanguage, confidence: 0.1 }], never 'und'.

    Parameters

    • text: string

      The input text to analyse.

    • Optional options: LanguageDetectionOptions

      maxCandidates caps the ranked list (3 unless given). method is not read.

    Returns Promise<LanguageDetectionResult[]>

    Ranked { language, confidence } pairs: ISO 639-1 codes ('en', 'fr'), confidences from 0 to 1.

parseJsonSafe

  • parseJsonSafe<T>(jsonString, options?): Promise<null | T>

  • The JSON the text holds, read as LLMUtilityAI reads it (parseReplyJson: the text as it is, else inside the first Markdown code fence it holds, backticks inside a sentence opening none, with a language tag or none and with words before or after it, up to the first later line that starts with as many backticks as opened the fence or more), then a check against targetSchema with Ajv when given, as LLMUtilityAI checks it: the standard formats checked, a keyword or a format Ajv does not know passed over, and a value coerced to the type its schema names where it can (targetSchemaChecks). Answers null when the text is empty or neither it nor a text inside a fence parses, when the value fails the schema, and when Ajv cannot compile the schema, the schema takes the draft-07 meta-schema's $id or it is marked $async. It repairs nothing: a HybridUtilityAI that holds an LLM-backed class sends a text this answers null for on to it.
