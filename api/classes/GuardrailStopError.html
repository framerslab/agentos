Class GuardrailStopError

A call that carried guards was stopped: by a rule (GUARDRAIL_BLOCKED), for a person's review (GUARDRAIL_HELD), or because a guard that runs closed could not judge (GUARDRAIL_UNAVAILABLE). Its message is one fixed sentence; it never holds a guard's reason, the prompt or the reply.
