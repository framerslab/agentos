withStorageTransaction

  • withStorageTransaction<T>(transaction, fn): Promise<T>

  • Uses this store's rows inside the host's existing storage transaction, so host writes and credit rows commit or roll back together. It neither begins, commits, retries nor closes a transaction: the host owns commit, rollback, retry and lock ordering, and an error reaches the host's enclosing transaction. The schema must already exist.
