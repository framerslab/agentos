sendClaimed

  • sendClaimed(candidate, send): Promise<boolean>

  • Sends one delivery as the table holds it now, not as due returned it: one gone or no longer pending is skipped (false). The signal send gets aborts when this outbox's purgeContent purges the delivery's run, so a send that has not written its body yet stops (false); any other rejection is send's. A purge committed through another instance or process reaches a send only through the re-read, so the manager that purges and the dispatcher take the same SqlOutbox.

      A delivery due returned.
