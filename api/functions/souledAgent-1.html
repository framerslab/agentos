Function souledAgent

  • souledAgent(opts): Promise<SouledAgent>

  • Create an agent with a soul and a per-person memory store. It runs on the GMI runtime with the light profile unless SouledAgentOptions.runtime names another: runtime: 'legacy' keeps the legacy path, and agent() keeps its own default.

    A workspace soul supplies its operator pages under memory/, the read_memory_page tool and a wiki compiled from each subject's stored traces. The subject is the named user or the anonymous session id. Recall combines that subject's memory with the operator's pages. A one-shot call without a subject reads only operator pages and files nothing. An inline soul or an optional soul that fails to load falls back to a plain agent.

    The light profile leaves cognitive memory off unless memory is set, scores no sentiment and runs no metaprompt, so the default needs no embedding model. The GMI runtime refuses the channels, voice and avatar options. It leaves a front-matter voice or avatar out with one soul.field_ignored line each, gives a session's history a share of the context window and reports what it left out in historyOmitted, and stops running session turns on close().

    On a workspace-backed agent on the GMI runtime with cognitive memory enabled, the GMI and wiki use the same durable store. The GMI files each accepted side of a session turn under the subject's key and recalls the traces it filed. The soul's memory provider recalls earlier and provider-filed traces and wiki pages. With cognitive memory off, the provider handles both filing and recall. Team seat sessions run with cognitive memory off.

    The workspace's three memory hooks apply on both runtimes, including with GMI cognitive memory enabled.

    • SouledAgentOptions.memoryPolicy chooses off, raw or compiled for the subject. off keeps no new long-term memory and recalls only operator pages. raw allows filing and recall without compiling new pages. compiled also allows wiki compilation, subject to SouledAgentOptions.compile. The latest policy answer for the subject on this agent takes effect on an open session's next turn.
    • SouledAgentOptions.screen can redact or drop text before filing and embedding and before compilation. A failed or timed-out policy or screening hook fails closed for the affected work.
    • SouledAgentOptions.sharedMemory assigns anonymous sessions and one-shot calls to the one named user on a personal machine or for an operator's notes.

    SouledAgentOptions.soulStore uses a host-owned SQLite or PostgreSQL adapter in place of the workspace's SQLite store. Supply retention, tombstoneKey and a separate tombstoneCopy. The host owns the adapter's lifetime. GMI cognitive memory uses the embedding provider you name. Its traces in the workspace-backed store carry a neutral emotional stamp by default. SouledAgentOptions.emotionalStamp can opt into storing the agent's mood, with neutral stamps still used for minors and subjects whose policy sets profiling: 'off'. GMI session requests omit the end-user id by default. Use SouledAgentOptions.sendUserIdToProvider to opt in with an opaque id.

    On a workspace-backed session, the memoryWrite promise on a send() or stream result reports each text side's write outcome without delaying the reply or carrying its text. SouledAgent.recipients lists the configured and recorded routes that receive text. Export, deletion, correction and retention operate on the unified store. With cognitive memory enabled and a passed GMI memory.store attached, SouledAgent.copyLegacyGmiMemory previews a move by default. Pass dryRun: false to move eligible traces to the soul's store and remove their source rows.

    Closing the agent gives in-flight turns and writes one deadline, set by SouledAgentOptions.pendingWritesTimeoutMs. It then sweeps expired memory, compiles from stored traces for the subjects whose turns wrote memory, where the policy allows it, and closes its own store handles. Call agent.memory.compileWiki() to compile without closing the agent. Closing a GMI session ends that session in process and preserves its durable memory under the same key, subject to retention and forgetting.

    Parameters

    • opts: SouledAgentOptions

      Agent options with a required soul.

    Returns Promise<SouledAgent>

    The SouledAgent. Its memory store and memory operations are available with a workspace soul.

    Throws

    SoulLoadError when a required soul fails to load.

    Throws

    TypeError for invalid sharedMemory, retention or compile.minors settings.

    Throws

    Error on the GMI runtime, which is the default, when channels, voice or avatar is set: the error names the option, and runtime: 'legacy' takes all three.

    Throws

    TypeError when GMI cognitive memory is enabled and memory.embedding.provider is missing or blank, a known model prefix routes to a different provider, or memory.consolidation.enabled is true.

    Throws

    TypeError when memoryPolicy, screen or sharedMemory is supplied with GMI cognitive memory enabled and the soul provides no workspace store.

    Throws

    TypeError for an invalid tombstoneCopy or soulStore, or when soulStore lacks an explicit copy, retention or tombstone key.

    Throws

    ForgottenLedgerError when the tombstone ledger cannot open, for example if its copy is unavailable or its existing keyed tombstones require a key.

    Throws

    Error when a workspace soul lacks a usable agent id, sharedMemory conflicts with an existing subject, or the store holds multiple subjects without retention or without a tombstone key on a ledger with no tombstones.

    Throws

    Error when soulStore conflicts with an existing workspace store file, its PostgreSQL adapter fails to return BIGINT values as numbers, or its database holds another agent's memory.
