Function costOfUsageUSD

  • costOfUsageUSD(providerId, modelId, usage, isEmbedding?): number | undefined

  • A finished call's cost: the provider's own costUSD when it reported one, else its tokens at the table's rates (modelPricing: OpenAI's and Anthropic's tables and a table the host registered); undefined when neither is known. A reported cost that is not a finite number, zero or more, is not used: a budget would record nothing for a cost of NaN. For a provider built on the OpenAI provider (Groq, LiteLLM, Mistral, Together, xAI, MiniMax), a row the host registered prices the call before the cost it reports, which is OpenAI's list price for the model id: the call is charged at the rate it was estimated at. A bill the provider's API returned (OpenRouter's and Requesty's usage.cost) stands.

    The prompt is inclusiveInputTokens where the report gives it (never fewer than promptTokens; for Anthropic, whose prompt tokens leave the cache out, the prompt tokens and the cache counts where it does not), so the cache reads and writes an Anthropic report keeps out of its prompt tokens are priced, and they count toward the long-context threshold; the long-context card prices the whole call where the prompt is over it. Of the prompt, the cache reads are priced at the card's cache-read rate (the input rate where the card has none); the writes the report names as made with the longer lifetime (cacheCreationExtendedInputTokens: Anthropic's cache_creation.ephemeral_1h_input_tokens, OpenAI's cache_write_tokens_details.ttl_12h_tokens) at the card's highest write rate (cacheWritePerMTokUSD: Anthropic's 1-hour write at 2x input, OpenAI's 12-hour write at 2.5x); every other write at the rate of a write with the provider's default lifetime (defaultCacheWritePerMTokUSD: Anthropic's 5-minute write and OpenAI's 30-minute write, both 1.25x input), the rate each provider bills a write at when the request names no lifetime. A report that does not split its writes by lifetime is thus priced as if every write had the default lifetime; a host row that names a single write rate (cacheWritePerMTokUSD alone) prices every write at that rate. The rest of the prompt is priced at the input rate. An embedding prices its prompt tokens alone, at the standard card.
