Optional reason

reason?: string

For every status but 'completed'. For 'budget_exhausted' it says whose budget refused (the launch's, or one the team draws on) and why: the launch's own token cap, once the launch's calls have used it up, as its count of the cap; any other refusal, a call whose estimate alone would pass what the cap has left among them, in the refusing cap's own words.
