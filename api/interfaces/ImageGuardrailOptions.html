Optional maxBytes

maxBytes?: number

The most bytes one image may hold. A larger image is refused with IMAGE_LIMIT and no check runs on it: base64 is measured before it is decoded, loadImage bytes as they come back. Default 20 MiB (20971520).

  • Defined in src/safety/guardrails/builtin/ImageGuardrail.ts:93

Optional timeoutMs

timeoutMs?: number

The deadline for one evaluation, every check of every image included. Default 15000 ms. Past it no further capture or check starts, an image whose checks had not all run, or whose last check was still running, is refused as unavailable unless a check blocked or held it, and the deadlineSignal every check received is aborted.

  • Defined in src/safety/guardrails/builtin/ImageGuardrail.ts:99

Optional sequential

sequential?: boolean

Sets config.sequential: the image checks finish before any phase 2 guard sees the input's text. Default false.
