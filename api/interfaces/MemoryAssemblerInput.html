Optional recallTraces

recallTraces?: ScoredMemoryTrace[]

The recall pool of retrieval: 'hybrid', in fused order. When set, the block shows it as one Relevant Memories section, in this order, on the recall share (unset: semanticRecall + recentEpisodic), with no Recent Experiences section, and retrievedTraces is not read.

Optional reservedIds

reservedIds?: string[]

Ids among recallTraces a memory question reserved room for (retrieval: 'hybrid'). Their whole lines are set aside in the recall section first, in their recallTraces order (not this list's), while they fit; the other lines fill what is left, in their order. A reserved line takes its place in recallTraces, so the caller puts them last to render them last. A reserved line that does not fit whole is left out like any other. Not read without recallTraces.

Optional graphContext

graphContext?: (string | MemoryGraphAssociation)[]

Graph association context (Batch 2): lines of text, or associations that carry the id of the trace they lead to. An association whose trace the block already holds (a retrieved trace rendered in Relevant Memories or Recent Experiences, or the involuntary memory) is left out of Related Context; a plain line is never left out for that.

Through 0.15.121 the field was string[]. Code that reads its elements as strings no longer type-checks; narrow each element first (typeof item === 'string' ? item : item.text).
