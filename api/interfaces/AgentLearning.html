Interface AgentLearning

What a host reads of an agent's learning layer, and the operator's calls on it (Agent.learning), with the agent's key (learning.agentKey, else a named agent's persona id) and namespace (learning.namespace) filled in. A call that names a user acts on that user's learner of this agent, and rejects, naming learning.agentKey, on an agent with no key. Every call runs in every mode, a freeze included. gmi() sets every member.
