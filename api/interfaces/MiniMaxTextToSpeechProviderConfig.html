Optional audioUrlHosts

audioUrlHosts?: string[]

Hosts that outputFormat: "url" audio may be downloaded from: an exact name such as "audio.example.com", or "*.example.com" for that domain's subdomains. MiniMax does not document the host its audio links use, so none is allowed by default and URL output fails, naming the host, until it is listed here. Only https links are downloaded.
