Properties

messages

messages: unknown

The messages (or a Responses API input) as the provider is sent them. A string counts as one message. The bound counts what the request carries: a request that draws in context stored with the provider (OpenAI's previous_response_id, conversation or a stored prompt) is billed for tokens its text does not show, so a host sends that context here or refuses the request.

Optional maxOutputTokens

maxOutputTokens?: number

The request's output cap: max_tokens, max_completion_tokens or max_output_tokens, as the request sends it. A call with none has no bound. A host that cuts a cap above the model's ceiling passes the cut cap: the ceiling a library table knows shapes a request, and is never taken as what the provider will bill.

n?: number

Completions asked for (n, best_of): each is billed its own output, so a request for more than one has no bound.

Optional cacheMarkers

cacheMarkers?: boolean

The request asks for prompt caching: cache_control on the request or a block (Anthropic), cache settings or a breakpoint (OpenAI's prompt_cache_options, prompt_cache_breakpoint, prompt_cache_retention). A cache_control or prompt_cache_breakpoint key in the messages, the system prompt or the tools counts as well.
