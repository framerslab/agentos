Optional order

order?: "date" | "rank"

rank: the highest rank first. date: the newest of the caller's dates first, an undated item after every dated one in rank order. Level items stand in the order of their source ids. A listing with no word is in the date order under either.

'rank'

Optional typo

typo?: "none" | "one-edit"

one-edit widens each word of four letters or more to the stored words of the group's own passages, of four letters or more, that are one edit away: a letter added, dropped or changed, or two side by side swapped.

Default

'none'

Optional expansionMax

expansionMax?: number

The most stored words one edit away that a word is widened to, the most frequent kept: a whole number from 1 to 64; a search asking for more is refused before the store is asked anything, as one tsquery holding more than 64 a word for 32 words would pass what Postgres reads. A word with more marks its group incomplete, and so does a stored word the store's query has no room for beside the search's words (on PostgresVectorStore, one tsquery of a mebibyte).

Default

64

pageSize: number

The most hits a group answers on a page: a whole number, 1 or more, that JavaScript holds exactly.

Optional cursor

cursor?: string

A later page of one group: the cursor an earlier page of the same search answered for it. The answer then holds that group alone. A cursor made for another search throws a LibraryCursorError, and so does any value but a cursor's text: the null a group answers after its last page is not read as a first page.

  • Defined in src/cognition/library/LibraryIndex.ts:214

Optional signal

signal?: AbortSignal

Stops the search: checked before each group and between the store's statements. Once it has aborted, the store is asked nothing more, and the group being read and every group after it answer incomplete with no hit; a group with no item is complete either way. The search does not reject on it.
