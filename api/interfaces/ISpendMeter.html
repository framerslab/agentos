Interface ISpendMeter

A persisted per-account meter. Every method is safe to call from several processes at once against one store: two reservations cannot both take the last unit, and a reservation settles exactly once.

interface ISpendMeter {

    reconcile(opts?): Promise<SpendReconcileResult>;

}
