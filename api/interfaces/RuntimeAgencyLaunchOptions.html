Interface RuntimeAgencyLaunchOptions

AgentOSConfig.agencies: whether the full runtime registers launch_agency, and every launch's bounds. launch: true registers the tool, which requires LAUNCH_CAPABILITY, so only a persona granted it lists and calls it. A seat is a GMI of the runtime's GMIManager: a registered persona a launch names by personaId (in place of agentKey), or a persona made for a temporary seat from the calling GMI's (its route, completion options, capabilities and hard limits, with the seat's instructions as its prompt). Every seat runs through a view of the runtime's tools that lists and runs its allowlist alone, as the parent turn's user and organization, with no cognitive memory, no retrieval and no learner.

Optional launch

launch?: boolean

Registers launch_agency among the runtime's config tools, for the personas granted agency:launch: a config tool of the host's own by that name then fails initialization. Default false. A seat whose call fails rejects with its error's name and code alone, so a provider's or a handler's message reaches no model of the team and not the result; the error itself goes to the runtime's logger (the one AgentOS.create takes, else its own), at warn, under launch_agency seat <role>, as do the launch's other failures (a failed run under launch_agency run). A logger that throws fails no launch. The output guardrails that judge the launching turn's tool calls (config.evaluateToolCalls) judge each call of every seat, a nested team's included, before it runs, beside the sources the launching turn retrieved, and a call they block is refused as the launching turn's would be. The usage the runtime's spend meter (spendMeter) records for the launching turn is that turn's own model calls: a team's calls are its seats' GMIs' and its coordinator's, which the launch's result reports (usage, coordinatorUsage).

Optional coordinator

coordinator?: {
    provider: string;
    model: string;
    apiKey?: string;
    baseUrl?: string;
}

The route of a launched team's manager and synthesizers (they call generateText). Default: the provider and model of the persona of the GMI that launched the team, else the GMIs' defaults (gmiManagerConfig.defaultGMIBaseConfigDefaults); when neither names a provider, the one the runtime's provider manager serves that model from, as for the GMI itself. A route that names neither apiKey nor baseUrl takes the key of the entry in modelProviderManagerConfig.providers the runtime serves its provider from (the last enabled one whose provider started), and sends it where the runtime's provider sends it: to that entry's base URL, else to the provider's own endpoint, never to a base URL a global default or an environment variable names. An entry with a base URL and no key gives its base URL alone to an Ollama route only. What the route takes nothing for, generateText resolves for the provider, key and base URL together, as for any call that names neither. A route that names either keeps what it names and takes nothing of the entry.
