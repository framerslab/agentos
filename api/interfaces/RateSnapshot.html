Interface RateSnapshot

A rate version: immutable once published, and kept by a call for its whole life. A component key names a billable quantity (media_second, input_token, output_token, reasoning_token, cached_input_token, tts_character and so on); the host chooses the keys, and every quantity it meters must have one.

interface RateSnapshot {
    version: string;
    currency: "USD";
    components: Readonly<Record<string, RateComponent>>;
    reasoningInOutput: boolean;
    attemptMinimum?: {
        customerMicro: number;
        supplierMicro: number;
    };
}
