Optional transcriptDelta

transcriptDelta?: SessionTranscriptMessage[]

Lossless message delta this call appended to the conversation: the request's user turn plus every assistant / tool turn the tool loop recorded, in order, in provider-replayable shape (tool_call ids, parallel results, thinking blocks). Sessions append THIS — never a reconstruction — to their history. Absent only on legacy paths that never seeded a conversation array. The prompt-shim path carries a partial delta (seeded turns only); native providers carry the full trail.

Optional servingProvider

servingProvider?: string

Upstream host that actually served the request when provider is an aggregator/router (OpenRouter reports e.g. 'Groq' or 'DeepInfra' per completion). Undefined for direct providers, for aggregators that omit it, and on the prompt-shim tool path. Latency attribution: identical model + token counts vary 3-5x in wall-clock by serving host, so telemetry needs this to interpret durations.

finishReason

finishReason: "length" | "error" | "stop" | "tool-calls"

Reason the model stopped generating.

  • "stop": natural end of response.
  • "length": maxTokens limit reached.
  • "tool-calls": loop exhausted maxSteps while still calling tools.
  • "error": provider returned an error.

An answer the model refused keeps the reason it reports here ("stop", or "length" when the output cap cut the refusal message off) and carries the message in GenerateTextResult.refusal.

  • Defined in src/api/generateText.ts:1142

Optional refusal

refusal?: string

The model's refusal message when it declined the request with one (OpenAI's refusal): present only when the model refused, and possibly the empty string. text is empty then, unless the model wrote text beside the message in the same reply: text keeps that text. finishReason is 'stop' beside a whole message, and 'length' when the output cap cut the message off, with the piece that came here. Read this field to tell a refusal from an empty answer. Set by generateText(); other surfaces that return this shape may leave it unset.

Optional historyOmitted

historyOmitted?: PromptHistoryOmission

On a gmi() or agent({ runtime: 'gmi' }) session's turn: the conversation history the turn's requests left out to fit the prompt engine's history budget (35 percent of the serving model's context window). messages counts the oldest messages left out of the request that left out the most, tokens is their size at the prompt engine's estimate; the session's messages() still lists them. undefined when every request of the turn carried the whole history, and on the default runtime, which sends the whole history.
