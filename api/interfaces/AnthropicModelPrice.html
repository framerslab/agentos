Interface AnthropicModelPrice

A Claude model's list prices in USD per 1K tokens, the shape a host's spend guard reads for OpenAI from openAIModelPricing: input for prompt tokens, output for completion tokens, cacheRead for prompt-cache hits, cacheWrite and cacheWriteOneHour for prompt-cache writes with the 5-minute and the 1-hour TTL (ANTHROPIC_CACHE_WRITE_MULTIPLIER and ANTHROPIC_ONE_HOUR_CACHE_WRITE_MULTIPLIER times input: "5-minute cache write 1.25x base input price", "1-hour cache write 2x base input price", https://platform.claude.com/docs/en/about-claude/pricing, read 2026-11-04), and longContext on a model Anthropic prices by prompt length, with the prompt size above which its rates apply.
