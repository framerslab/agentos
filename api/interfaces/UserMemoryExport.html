Interface UserMemoryExport

One subject's memory: what they and the agent said, as the store holds it, and the pages compiled from it; what the subject provided and what is held about them; who receives a person's text; how long it is kept; and whether the subject is profiled.

Type declaration

  • traces: HeldTrace[]

    Each of the subject's traces, oldest first, with what the store keeps of it.

  • archivedOriginals: {

        text: string;
    }[]

    The verbatim text an archive keeps of a held trace, where one does.

  • typedFacts: []

    Typed facts extracted from the subject's traces: none, as no souled agent extracts them.

  • graphLinks: {
        from: string;
        to: string;
        type: string;
        weight: number;
    }[]

    Links between two held traces from the store's graph and the live cognitive memory graph.

  • pages: ExportedPage[]

    The pages compiled from the subject's traces, as UserMemoryExport.pages.

  • Optional learner?: LearnedStateDocument

    The subject's learned state, when the agent runs a learning layer.

  • Optional legacyGmiStore?: {
        id: string;
        createdAt: string;
        speaker?: "user" | "assistant";
        text: string;
    }[]

    Live traces of the subject in a passed GMI store, oldest first: those under their user and persona scopes, under the scopes of their sessions that store's learning tables index, and a turn's rows filed for them as a second user. A deletion removes the same rows.

  • restoreCopies: {
        traceId: string;
        text?: string;
    }[]

    The corrections of the subject whose text the tombstones' second copy also keeps. text is given for one the export holds no trace of: a restore of the store took it, and filing it again has not succeeded yet, so the copy is the one place that holds those words.
