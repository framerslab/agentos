maxBytes

maxBytes: ((kind) => number)

The most bytes an entry of each kind may hold, and, for archive, the most a nested archive may hold for the plan to open it: 0, any positive number or Infinity. An entry whose size is no byte count (a finite number of 0 or more) is skipped with the reason size; a bound below 0, NaN or no number at all (null, a numeric text such as '5', true, an object) rejects the plan with a RangeError.
