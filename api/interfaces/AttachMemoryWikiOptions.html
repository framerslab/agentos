Optional ownPagesServed

ownPagesServed?: ((scopeKey) => boolean | Promise<boolean>)

Whether a subject is served its own pages, by the key they are filed under: false reads and lists the operator's pages alone for it, and its own pages answer as pages that do not exist. A host whose policy keeps no memory for an account answers false for it. Unset, every subject is served its own pages.

Optional isForgotten

isForgotten?: ((subject) => Promise<boolean>)

Whether a subject is forgotten: the forgotten-user ledger's check (ForgottenLedger.isForgotten). With it, a forgotten asker of read_memory_page gets no page and an empty listing, a forgotten subject's scope is not compiled, and a page a compile wrote after the subject's tombstone is deleted once that compile is done. Each refusal writes one line with the reason forgotten.
