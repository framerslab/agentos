Optional supplierUsageInbox

supplierUsageInbox?: IDurableInbox<PendingSupplierUsage>

Optional. Where supplier totals wait when the entitlement hook's recordSupplierUsage refuses them (a report's, or those a provider's usage answers at reconciliation), until the next MeetingManager.reconcile hands them over again; a durable inbox (SqlDurableInbox) keeps them across a restart. A refusal holds back no run either way: the report is applied, and a run whose worker is gone still ends. Without an inbox, the hook's error is thrown once the report is applied, or at the end of the reconcile pass.
