Interface SourceDeletionTombstone

Recovery evidence contains opaque keys and counters, never derived content. sequence orders the records in commit order, epoch is the owner's fence counter the deletion set, at is when it was recorded (the store's clock, integer UTC epoch milliseconds) and ownerDisabled says whether the deletion left the owner inactive.
