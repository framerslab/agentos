Interface MemoryRetention

How long a souled agent's store keeps what people said.

A store that holds, or would hold, the memory of more than one user or session does not open, and opens no second subject's session, without it.

interface MemoryRetention {
    traces: RetentionPeriod;
    sessions?: RetentionPeriod;
    pages?: "delete-whole" | "rebuild";
}

Optional pages

pages?: "delete-whole" | "rebuild"

What happens to a per-user page when a trace it was compiled from expires. 'delete-whole' (the default) deletes the page; 'rebuild' deletes it and has the next compile build it again from the traces that are left, one model call a page, charged to the budget.
