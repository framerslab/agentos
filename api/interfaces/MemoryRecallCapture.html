Type declaration

    The configured budget of the block (recall.budget.totalTokens, or the caller's).

  • effective: number

    The budget the block was rendered in.

  • Optional clampReason?: "prompt_share" | "zero_remaining"

    Set when a model's share of the prompt held less than requested: zero_remaining when nothing was left.

  • Optional promptShareTokens?: number

    The serving model's retrieved-context share, in tokens (a GMI turn's record).

  • Optional otherContextTokens?: number

    The turn's RAG and long-term-memory text, in tokens, which the share holds first (a GMI turn's record).

  • Optional hop?: number

    The model hop the record is for, 0 for the route's primary (a GMI turn's record).

  • Optional reassembled?: boolean

    True when the block was rendered again at effective from the turn's recall, with no second retrieval.

  • Optional renderFailed?: boolean

    True when rendering the block again for the hop failed, so the hop was sent no block (a GMI turn's record).

Optional delivery

delivery?: {
    memoryBlockTokens: number;
    otherContext?: {
        ragTokens: number;

        cutBy?: "prompt_engine_truncate" | "prompt_engine_summarize";
    };
    issueCodes?: string[];
    promptReplacedByHook?: boolean;
}

What reached the model, once the prompt was built (a GMI turn's record): PromptEngine's count of the memory block, which it never reduces; the other retrieved context the turn had (ragTokens, longTermMemoryTokens, by the assembler's estimate) and what of it was sent (deliveredTokens, by PromptEngine's), with cutBy when PromptEngine reduced it; and the codes of PromptEngine's issues about the context (RAG_SUMMARIZATION_FAILED, TOKEN_BUDGET_EXCEEDED_POST_OPT). promptReplacedByHook is true when the host's beforeModelCall replaced the prompt for the hop: the counts are then of the prompt PromptEngine built, and what the model received is the hook's.
