Interface SeatHandle

A roster member that runs one session of its own; built by sessionSeat and by launch_agency. Its first call opens the session, and fails when the member already serves a session under the seat's id: generate() rejects and stream() throws, with the TypeError that names the id (a launch's seat, with that error's name alone).

interface SeatHandle {
    seatId: string;
    record(): LaunchSeatRecord;
    generate(prompt, opts?): Promise<unknown>;
    stream(prompt, opts?): AgentStreamResult;
    session(id?): unknown;
    usage(sessionId?): Promise<unknown>;
    close(): Promise<void>;
    listen?(opts?): Promise<{
        port: number;
        url: string;
        close: (() => Promise<void>);
    }>;
    connect?(): Promise<void>;
    export?(metadata?, options?): unknown;
    exportJSON?(metadata?, options?): string;
    description?: string;
    dependsOn?: string[];
}

  • Starts a loopback WebSocket listener on 127.0.0.1 that exchanges JSON text: { "text": "..." } in, { "text": "..." } out, one request at a time per connection.
