Optional playbackTimeoutMs

playbackTimeoutMs?: number

Deadline for each write and each playback checkpoint; default 10000 ms, maximum 30000 ms. A chunk with a generation has it for its writes and its checkpoint together; a chunk without one, written in order, has it for its checkpoint from when it is the oldest written chunk awaiting one.
