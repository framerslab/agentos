providerConnectionRef?: string

The provider's opaque reference for the connection the run was sent through (a credential's generation, for example). The content-free row keeps it, so the runs sent through one connection can still be found, and their kept content purged, after the connection's credentials are gone. It names no person and carries nothing of the meeting.
