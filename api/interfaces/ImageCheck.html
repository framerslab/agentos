check

  • check(image, context): Promise<ImageCheckResult>

  • Judges one image: receives the guard's own copy of its bytes (never a URL) with the guard's deadlineSignal, and the call's context, and answers an ImageCheckResult. A throw, or any other answer, is a check that could not answer. Once image.deadlineSignal is aborted, send nothing, and stop a request in flight (hand the signal to it).

Optional onError

onError?: "refuse" | "skip"

What a throw, or an answer with no verdict, does. refuse (default): the image is refused as unavailable. skip: the check is a signal; its failure is written and the chain goes on. A match check is always refuse.

Optional reasonCodes

reasonCodes?: readonly string[]

Every reason code and review code the check can answer. The guard's config.reasonCodes is its own fixed codes and every check's list. A vendor's check lists its category codes.
