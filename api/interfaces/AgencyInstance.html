Optional listen

  • listen(opts?): Promise<{
        port: number;
        url: string;
        close: (() => Promise<void>);
    }>

  • Starts a loopback WebSocket listener on 127.0.0.1 that exchanges JSON text: { "text": "..." } in, { "text": "..." } out, one request at a time per connection. It performs no speech recognition or synthesis; a binary frame receives an audio_not_supported error and close code 1003. Present on agency instances created with voice: { enabled: true }. Spoken calls use VoiceSessionFactory.

    Parameters
