Interface SourceDerivationBindings

Host/table bindings must operate only on the supplied transaction adapter. The store calls them inside its owner lock, in the transaction that commits, delivers or purges. Never fetch from a provider, parse, embed, generate or revoke inside them.

readCurrent

  • readCurrent(tx, derivation): Promise<readonly SourceDependencyState[]>

  • Reads the current state of each of the derivation's sources from the host's own rows, in this transaction: connection generation, source version, retained message ids, source expiry and the pause and use switches.
