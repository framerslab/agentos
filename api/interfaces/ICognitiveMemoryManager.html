  • Replaces recall settings on a built manager, field by field over the ones it holds: for a host or a bench that is handed a manager it did not construct. The values are checked as at construction. Optional deleteScope

  • deleteScope(scope, scopeId, options?): Promise<MemoryDeletion>

  • Delete every trace of one scope for good, as an account deletion needs: its memory-graph node, its original in the configured archive and the typed facts extracted from it, then the trace in the cache (every store over the Brain in this process keeps none of its words), the vector index and the Brain, and the knowledge graph's episodic copy (MemoryStore.deleteScope). With no Brain, the scope's documents in the vector index are found and deleted too, those another store filed before a restart included. With turnUserId, only the scope's traces that user filed as a second user on the session (MemoryTrace.turnUserId). Optional, so a host's own implementation keeps compiling.

    Parameters

    • scope: MemoryScope
    • scopeId: string
    • Optional options: {
          turnUserId?: string;
      }
      • Optional turnUserId?: string

    Returns Promise<MemoryDeletion>

    Throws

    TypeError when scopeId is empty, so a caller's missing id never deletes every trace filed under no scope id, or when turnUserId is given and is not a non-empty string.
