Interface PromptComponents

Core components that form the foundation of any prompt construction. These are gathered from various sources (GMI state, user input, RAG) and then augmented with dynamically selected contextual elements.

Optional systemCacheMarker

systemCacheMarker?: {
    ttl?: "5m" | "1h";
}

Asks the chat template to send the leading run of fixed system entries (persona or conversation, none of them blank) apart from the rest, for a target in the Anthropic family: on the anthropic provider as a text part that carries a cache marker (ttl: '1h' gives it a one-hour lifetime), followed by the rest as a plain system string; on OpenRouter with an anthropic/ model as two system strings, which that provider marks. The text and its order are unchanged: the system messages joined with a blank line are the single string sent without this field. Unset, or on any other target, the system text is that single string. The GMI sets it per model hop.

Optional currentTurnMessageCount

currentTurnMessageCount?: number

How many messages at the end of conversationHistory belong to the turn being answered: the current user message when it travels as history (structured input), then the assistant tool calls and tool results of the turn's earlier calls. Token budgeting summarizes or truncates only the messages before them, so the model always receives the request it answers and its own tool rounds. A tool round the first of them belongs to is kept whole with them: a call before them whose result they hold is not dropped. Defaults to 0.

Optional memoryContextText

memoryContextText?: string

The turn's cognitive memory block, set by the GMI: the text of the rendering the serving model's budget allows. PromptEngine counts it into the prompt's tokens and never summarises or truncates it; when the prompt must be reduced, only retrievedContext is. After the budget step it is placed before retrievedContext, joined to it with \n\n---\n\n (as the first entry, with source: 'cognitive_memory', when retrievedContext is a list). The GMI sets it only on an engine whose acceptsMemoryContextText is true; on any other it joins the block in front of retrievedContext.
