Interface SpendDayStore

The rows a day's bound needs, kept by the caller; every method runs inside the caller's transaction. A store that holds fenced reservations says so with fencedReservations and implements addFencedReservation and deferReservation, persisting the fence, the next check and the evidence in the caller's transaction. A store without that capability cannot admit a fenced reservation or run a sweep with a resolver. A store that holds operation reservations says so with operationReservations and implements addOperationReservation, openOperationReservation, beginRun, endRun and renewRun; a store without them cannot admit an operation.

}
