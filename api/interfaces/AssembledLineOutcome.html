Interface AssembledLineOutcome

What became of one line of the memory block that shows a memory: a retrieved trace's line, a graph association that carries the id of the trace it leads to, or the involuntary memory. Such a line renders whole or not at all.

    outcome: "included" | "left_out";
    reason?: "budget" | "section_full";

}
