  • putSessionRow(row, expectedVersion?): Promise<void>

  • Inserts the row, or writes it over the row of the same learner, session and kind, keeping that row's startedAt. transaction

  • transaction<T>(fn): Promise<T>

  • Runs fn in one transaction: every write it makes through tx commits together, or none does when it throws. fn makes every call through tx, never through the store: a call on the store runs outside the transaction, and a store that runs one call at a time holds it until the transaction ends, so a transaction that waits for it never ends.
