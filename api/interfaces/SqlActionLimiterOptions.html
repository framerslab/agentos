rules

rules: readonly ActionLimitRule[]

Every rule the host uses. The limiter builds its meters from this list, so a process that never reserves (a deletion job, a nightly purge) still knows every window and every key. reserve() throws for a rule that is not here or whose numbers differ: a configuration error, which a governed tool ends as limiter_unavailable.

Optional tablePrefix

tablePrefix?: string

Default agentos_action. Each distinct windowMs gets one SqlSpendMeter under <prefix>_w<windowMs>. That whole name must pass the meter's own rule (a lower-case letter and at most 37 more characters), so the constructor refuses a prefix and a window that together run past it.

Optional leaseMs

leaseMs?: number

How long a reservation lives without a renewal. Default 60000. A governed tool renews it three times a lease while its tool runs, so it runs out only when no renewal succeeds for a whole lease: the process that holds it stopped, or the store did not answer. A lease that runs out while the tool runs counts the action. The constructor refuses one that is not shorter than every rule's windowMs.
