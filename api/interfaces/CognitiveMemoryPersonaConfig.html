Interface CognitiveMemoryPersonaConfig

A persona's cognitive memory settings. createAgentCognitiveMemory passes each field but featureDetectionStrategy to the manager it builds, under the same name in CognitiveMemoryConfig; a field or key left out, or set to undefined, keeps the default. The type lists no null, and a loaded persona holds none: normalizePersonaDefinition, which the file-system PersonaLoader and InMemoryPersonaLoader run and GMIManager runs again on every definition any loader returns (a host's own IPersonaLoader included), drops a field set to null, a key set to null inside a field, and a cognitiveMemoryConfig set to null, as a persona read from JSON writes an unset key. A host that builds its manager from a persona itself (gmiManagerConfig.cognitiveMemoryFactory) gets the persona so normalized, and passes the fields the same way. agent({ runtime: 'gmi' }) and gmi() build their persona from their options, which set only cognitiveMemoryConfig.recall, from memory.recall.

}

Optional tokenBudget

tokenBudget?: Partial<MemoryBudgetAllocation>

Token budget share overrides (fractions of the block's budget; shares adding up to more than 1 are scaled down, and a share that is not a finite positive number counts as 0). Unused budget flows to the sections that still have content. A share of exactly 0 turns its section off: it gets no grant and no unused budget. A key left out or set to undefined keeps its default share (a persona loader drops a key a JSON file sets to null). createAgentCognitiveMemory passes it to the manager it builds as CognitiveMemoryConfig.tokenBudget; a host that builds its manager from a persona itself (gmiManagerConfig.cognitiveMemoryFactory) passes it the same way. agent({ runtime: 'gmi' }) and gmi() build their persona from their options, which set only cognitiveMemoryConfig.recall, so their memory runs on the default shares.

Optional recall

recall?: MemoryRecallConfig

Recall settings (CognitiveMemoryConfig.recall): the memory block's budget, the capture, the retrieval and the rerank. createAgentCognitiveMemory passes them to the manager it builds, under the agent's own memory.recall. A JSON persona can hold rerank: 'none' or a local setting; an llm setting holds a function, so a persona built in code sets it.
