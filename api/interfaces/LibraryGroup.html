items

items: LibraryGroupItem[]

The items the search may read, each once: the search reads the passages of these sources and no other, for a match, a count, a rank or a stored word to widen to. An empty list finds nothing, without a call to the store.

  • Defined in src/cognition/library/LibraryIndex.ts:156

fingerprint

fingerprint: string

The caller's name for this list as it stands, any text that is not empty: a cursor keeps the one its page was made under, and a later page handed another answers restart. The index compares it and never computes it.
