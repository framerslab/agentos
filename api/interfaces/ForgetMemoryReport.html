complete

complete: boolean

False when anything was still pending at the deadline, a store the call deletes from failed (the full-text index, the vector index and the write-ahead log included), a page failed, or the store holds memory from before per-user scope that nobody attributed. The stores the call never reaches by design are named and do not count. The next open, or the next re-application of the tombstones, resumes an incomplete deletion.
