Interface ForgetMemoryReport

What a deletion did: the receipt a host keeps beside its own record of the request, which is what links the receipt to the person. It never holds the subject's id, a hash of the id or any text of theirs.

complete

complete: boolean

False when the passed GMI store was missed, anything was still pending at the deadline, or a part of parts was not reached: a store the call deletes from failed (the full-text index, the vector index and the write-ahead log included), a page failed, the store holds memory from before per-user scope that nobody attributed, or open sessions kept what they hold of the subject. The stores the call never reaches by design are named and do not count. The same call made again resumes an incomplete deletion. The next open or tombstone replay retries when the soul store names the subject, the passed GMI store names the user in its learning tables or a trace's turnUserId, or the active learning store names the user in its namespace. Replay also deletes traces that are present again by their recorded trace ids.

parts

parts: ({
    part: "tombstone" | "mind" | "store" | "sessions";
} & PartOutcome)[]

The deletion's four parts, always in this order, each reached with a count or missed with the reason:

  • tombstone: reached once the ledger holds the subject's tombstone; it deletes nothing itself, so its count is 0.
  • mind: what an agent's mind held of the subject, deleted through it (mind): reached with the number of rows it deleted, 0 where it holds none or none of its memory is open in this process, and missed with the reason when its delete failed, which leaves the keys it failed on as they were for the deletion made again.
  • store: the store's own pass. Reached, with the number of traces deleted, when every store the call deletes from was reached (the caller's own included), every page was deleted and no memory from before per-user scope is left unattributed; missed with each of those that failed.
  • sessions: what open sessions hold of the subject, as the caller's sessions option answered; reached with 0 when the caller passed none.
