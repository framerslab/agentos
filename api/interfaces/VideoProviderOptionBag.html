Interface VideoProviderOptionBag

Provider-specific model inputs for a video request.

Keyed by provider id ({ fal: {...}, replicate: {...} }), each provider in a fallback chain receives only its own entry; the ids of providers added with registerVideoProviderFactory() key a bag as the built-in ids do. A bag with no provider-id key goes whole to fal, Replicate and Gemini. The entries add model inputs and never replace a field the request sets (the prompt, the image, the duration, the resolution and the like): to send a model-specific value for such a field, leave the typed field unset and put the value here. The Runway provider sends no provider options.

interface VideoProviderOptionBag {
    fal?: Record<string, unknown>;
    replicate?: Record<string, unknown>;
    runway?: Record<string, unknown>;
    gemini?: Record<string, unknown>;
    [providerId: string]: unknown;
}
